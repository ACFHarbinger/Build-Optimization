# C++ Backend Reference

The `backend/` solver core reference is generated with **Doxygen** from
`backend/include/` and `backend/src/`.

## Build locally

```bash
doxygen docs/cpp/Doxyfile
```

Open `docs/_build/api/cpp/index.html`, or run `bash docs/build_docs.sh` to
build everything and copy it into `site/api/cpp/`.
