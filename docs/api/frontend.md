# Tauri Frontend Reference

The `frontend/src` (React + TypeScript) reference is generated with
**TypeDoc**.

## Build locally

```bash
npm install
npx typedoc --options docs/frontend/typedoc.json
```

Open `docs/_build/api/frontend/index.html`, or run `bash docs/build_docs.sh`
to build everything and copy it into `site/api/frontend/`.
